# Frontend source

The visual HTML/CSS shell and crayon.svg/favicon.svg were adapted from
the Crayon-Web source archive supplied by Pratham on October 9, 2026,
original project https://github.com/uttiyabiswas2027-stack/Crayon-Web.
Pratham relayed Uttiya's verbal permission to use it on October 9, 2026.
This records scoped reuse permission, not a claim that the upstream project has
an open-source license. Upstream anonymous chat backend and browser Python
worker were not incorporated. Authentication, web transport and application
logic here use the itsppm76/crayon backend.
